# 일곱 서약 — 에셋 스펙 v1.5 (단계 2: 버티컬 슬라이스)

이 문서는 도트 세션 · 사운드 세션 · 메인(코드) 세션 사이의 **계약**이다.
파일명·태그명·캔버스·타격 프레임을 바꾸면 코드가 깨진다. 바꿔야 하면 LOG에 제안으로 적고 메인 세션에 알린다(메인 세션이 이 문서를 고친다).

## 0. 작업 영역 (세션별 소유권)

## 1. 도트 공통 규칙
- **내부 해상도 480×270** (게임 화면 전체). 1픽셀 = 화면 1픽셀. **캔버스 크기 ≠ 캐릭터 크기**.
- **PPU 32**, Point, 무압축. 원본 `.aseprite`. **태그명 = 애니메이션 상태명**(소문자 snake_case, 아래 표 그대로).
- 피벗: 캐릭터 = **캔버스 바닥 중앙**(발이 캔버스 맨 아래 줄에 닿게, 가로 가운데). 이펙트·소품 = 중앙(예외는 표에 적음).
- **시점: 3/4 사선뷰** — 몸통이 카메라 쪽으로 30~45° 틀어진 모습. 이동 방향은 좌우.
- **방향: 전부 오른쪽을 보는 기준.** 코드가 좌우 반전한다.
- 광원: **위쪽 정면**(좌우 대칭) — 반전해도 어색하지 않게. 분위기 조명은 Unity 2D 라이트가 더한다(그림에 강한 방향광 금지).
- 외곽선: 재질별 셀렉티브(머리카락·피부 = 그 색의 어두운 톤, 검은 옷·금속 = 가장 어두운 색).
- 미리보기: `ArtSource/previews/`에 4배 PNG/GIF. 실제 화면 크기 비교는 480×270 목업 위에 1:1로 얹어 확인.

## 3. 사운드 공통 규칙
- SFX: **WAV 44.1kHz/16bit/모노**, 피크 −1dBFS, 앞 무음 0, 짧게.
- BGM·앰비언스: **OGG(q≈6) 44.1kHz 스테레오, 끊김 없는 루프**.
- 톤: **다크 판타지, 무겁고 정직한 타격**. 칩튠 아님. 타격음은 레이어(둔탁한 트랜지언트 + 강철 공진 + 저음)로 크게, 단 귀를 찌르는 고음은 억제.
- **검은 수정처럼 보여도 소리는 강철·철**(사용자 지시, v0.4). 이펙트 그림은 수정 파랑 그대로.
- 자주 나는 소리는 변형 3종 이상(`_01` `_02` …) — 코드가 랜덤 + 피치 ±3% 재생.
- 실존 곡·효과음 모방 금지.

## 5. 코드가 아트를 쓰는 방식 (참고)
- 공격 애니메이션은 **3구간**으로 재생된다: 선딜 = 타격 프레임 이전 프레임들, 판정 = 타격 프레임(부터 판정 길이만큼), 후딜 = 나머지. 각 구간 길이는 GDD 프레임 데이터를 따르고, 구간 안에서 프레임을 고르게 나눈다. → **공격 태그의 ms 값은 무시되고, 타격 프레임 위치만 중요하다.**
- 타격 프레임 = 칼날이 가장 앞으로 뻗은 순간(스미어 프레임 권장). 그 앞 프레임들 = 들어올림·버팀, 뒤 = 휘두른 뒤 무게가 남는 자세.
- 이펙트 `play` 태그는 적힌 ms 그대로 재생 후 사라진다. `fx_slash_*`는 해당 공격의 타격 프레임에 맞춰 캐릭터 위에 겹친다.
- 히트스톱 동안은 모든 애니메이션이 멈춘다 → 타격 프레임이 한 장면으로 오래 보이므로 가장 멋있게.
