# 사운드 작업 로그 (사운드 세션)

최종 갱신: 2026-11-21 (16차: 칼 넣는 소리 v2) · 담당: 사운드 세션 · 스펙: `Docs/ASSET_SPEC.md` 3~4절(v1.3)

## 상태 요약
- **스펙 4절(v1.3)의 파일 + 추가 요청분 = 88개**가 있다: SFX 83개(WAV 44.1k/16bit/모노), BGM 3개·앰비언스 2개(OGG Vorbis 44.1k 스테레오, 끊김 없는 루프). `bgm_boss`(사용자가 가져온 무료 곡, `Docs/CREDITS.md`)를 빼고 전부 `AudioSource/`의 Python 스크립트로 직접 합성했다. 샘플·실존 효과음은 쓰지 않았다.
- 측정 검사 **전부 통과**(`python AudioSource/analyze.py`): 트루 피크 ≤ −1 dBTP, 클리핑 0, DC < 0.001, SFX 라우드니스 목표 ±0.1 LU, 5–10 kHz 대역 제한, 루프 이음새 클릭 없음.
- 미리듣기: **`AudioSource/preview.html`을 크롬/엣지에서 직접 열기**. 카드별 재생 + 전투 박자 시뮬레이션(3연 베기, 회피 캔슬, 차지 2단, 대쉬, 처형, 병사 교전, 허수아비, 이동, 수련장 믹스, **보스전 믹스**) + 카드별 "좋음/고쳐줘 + 메모" → "피드백 복사".

## 타격감 설계 (GDD "타격감 레이어"의 사운드 줄)
| 등급 | 파일 | 길이 | LUFS-M | 노트북 스피커 근사* | 구성 (전부 강철·철) |
|---|---|---:|---:|---:|---|
| 약 | `sfx_hit_light_01..04` | 1.0 s | −19.5 | −19.5 | 날카로운 강철 '챙': 쇳소리 어택 + 620 Hz부터 위로 뻗는 강철 모드 14쌍(울림 0.2 s대) + 1.25 kHz 칼날 울림 + 칼날 긁힘 '스링' 60 ms + 짧은 충격 + 불꽃 12알 |
| 강 | `sfx_hit_heavy_01..03` | 1.5 s | −16.5 | −17.0 | 더 크고 긴 강철 '깡—': 420·760 Hz 강철 판 2장 + 980 Hz 칼날(울림 0.4 s) + 긴 긁힘 120 ms + 불꽃 소나기 34알 + 55 Hz 낮은 울림(스윕 없음) + 큰 룸(RT 0.8) |
| 마무리 | `sfx_hit_finisher` | 2.6 s | −13.5 | −15.9 | 짧은 '칭' → **0.14 s 지점 폭발**(그 사이 −40 dB 정적 = GDD "0.1초 무음 뒤 폭발"을 파일에 구움): 260 Hz부터의 거대한 강철 굉음 + 540 Hz 판 + 820 Hz 칼날 긴 울림 + 긴 긁힘 + 갑옷 터짐·불꽃 + 쇳조각 7개가 0.3–1.1 s에 떨어짐 + 낮은 붐 + 짧은 홀(RT 1.05) |
| 처형 | `sfx_execute` | 2.7 s | −14 | −15.2 | 들숨 + 낮은 긴장음(0–0.27 s) → 30 ms 정적 → **0.300 s에 꽂힘**(200 ms 칼날 긁힘 + 날카로운 강철 '깡' + 살 + 낮은 붐 + 돌 균열) |
| 자세 붕괴 | `sfx_poise_break` | 1.6 s | −17 | −21 | 낮은 충격 + 판금 우그러짐(철 모달 2장) + 삐걱 '금 가는' 스틱슬립 + 균열 알갱이 + 가라앉는 저음 |

\* 250 Hz 아래를 자른 LUFS-M(작은 스피커 근사). 저음이 안 나오는 스피커에서도 약 < 강 < 마무리가 유지되는지 확인용.
- 귀 피로 대책: 날카롭게 만들었지만 8 kHz 위는 4차 로우패스로 깎았다(5–10 kHz 대역: 약 −27~−30 dB, 강 −23~−31 dB, 전체 대비). 자주 나는 휘두르기·회피·발소리는 5.5 kHz 이하.

## 라우드니스 기준과 권장 믹서 볼륨
BS.1770(K-weighting). 모노 SFX는 듀얼 모노(+3 dB)로 계산. **레벨을 파일에 구웠으므로 AudioSource 볼륨은 1.0 기본.**

| 믹서 그룹 | 파일 레벨 | 권장 그룹 볼륨 | 실효 |
|---|---|---|---|
| BGM | `bgm_training`·`bgm_region1` −18 / `bgm_boss` −17 LUFS-I | **−8 dB** | ≈ −26 / −25 LUFS |
| Ambient | `amb_cloister`·`amb_rampart` −24 LUFS-I | **−6 dB** | ≈ −30 LUFS (보스전에서는 끄거나 −12 dB 권장) |
| SFX | 소리별 목표(아래) | **0 dB** | |
| Master | | 0 dB | |
- 마무리·처형 때 BGM을 1초간 −4~−6 dB 덕킹하면 무게가 더 산다(선택).

## 스펙과 다른 점 · 제안 (메인 세션 확인 요청 → ASSET_SPEC 수정 부탁)
1. **검 소리에서 '수정'을 전부 뺐다(사용자 지시: "수정검처럼 보이지만 수정검의 소리가 나면 안 돼")**. ASSET_SPEC 4절의 다음 설명을 바꿔야 한다:
   - `sfx_swing_*` "아주 옅은 수정 울림" → 울림 없음 / `sfx_hit_heavy_*` "수정 파편" → 쇳조각 / `sfx_hit_finisher` "유리 깨지는 수정" → 거대한 판금 굉음 + 갑옷 터짐 / `sfx_perfect_dodge` "수정 반짝" → 음이 처지는 강철 울림 / `sfx_charge_loop` "수정 웅웅" → 강철이 버티는 웅웅 / `sfx_dash_*` "수정 울림 꼬리" → 낮은 바람 꼬리.
   - 3절 톤 규칙에 "검은 수정처럼 보여도 소리는 강철·철"을 추가하면 좋겠다. (이펙트 그림은 그대로 수정 파랑.)
2. **`bgm_boss.ogg` 추가**(사용자 요청). 4절 BGM 표에 `bgm_boss.ogg | 60~90초 루프 | 보스전: '성전' 오케스트라 — 튜티 타격 + 합창 주제(종·오르간·금관·팀파니·큰북), 96 BPM D단조` 줄 추가 부탁. 지금은 1번 기사(철벽) 보스용 공용 곡. 기사별 곡이 필요하면 `bgm_boss_<기사>.ogg`로 늘리자.
3. "피크 −1 dBFS"는 상한으로 해석(모든 파일 TP ≤ −1 dBTP). 레벨은 소리별 라우드니스 목표로 구웠다.
4. `sfx_execute`·`sfx_dash_*`는 **동작 시작에 재생**(꽂힘 @0.300 s, 돌진 @0.083 s). `sfx_hit_finisher`의 "0.1초 무음 뒤 폭발"은 파일에 구워짐(코드 지연 불필요).
5. 허수아비는 `dummy_hit`을 타격음 **대신**(강 등급은 heavy −8 dB 겹침).

6. 9차 요청서의 '유리 같은 팅'·'수정 깨지는 소리'·'수정 차임'은 사용자 규칙(검은 수정처럼 보여도 소리는 강철·철, v0.4)에 맞춰 **금속 종·강철 파편·금속 차임**으로 만들었다. 수정 소리가 꼭 필요하면 사용자 확인 후 바꾼다.

7. `bgm_boss`는 외부 곡. 라이선스 조건상 **음악 자체 배포 금지** → 원본 mp3 사본(`AudioSource/import/`)은 git 제외로 해 두었다. 게임 빌드 안의 OGG는 사용 범위. 스펙 4절 BGM 표의 `bgm_boss` 설명도 이 곡으로 갱신 부탁.

8. 16차 요청의 '수정검 느낌(맑은 유리·수정 울림)을 살짝'은 사용자 규칙("수정검처럼 보여도 수정검 소리가 나면 안 돼")과 충돌해 넣지 않았다. 대신 짧고 맑은 강철 여운으로 밝기를 줌. 꼭 필요하면 사용자 확인 후 추가.

## 측정 방법 · 재생성
- 전체: `cd AudioSource` → `python render_all.py` (외부 곡 `import_bgm.py` 단계 포함; 원본 mp3가 `AudioSource/import/`에 있어야 함) (약 1분 10초). 순서: `make_sfx.py` → `make_bgm.py` → `make_amb.py`(무손실 마스터 `build/masters/*.wav`, git 제외) → `encode_ogg.py`(OGG 변환·디코드 재검증 후 Assets에 넣음) → `analyze.py` → `build_preview.py`.
  - 개별: `python make_sfx.py [이름 일부]`, `python make_bgm.py [training|boss]`, `python make_amb.py`
  - 측정: `python analyze.py` → `report/metrics.json`, `report/spec_*.png`, `report/seam_*.png`, `report/ltas_*.png`
  - 보조: `python bands.py [이름 일부]`(대역 비율 + 노트북 스피커 근사), `python wave_sheet.py <이름 일부>`(파형·엔벨로프), `python long_sheet.py <파일>`(긴 파일 스펙트로그램 + 단기 라우드니스)
- 툴킷: GameDevKit `audio/`를 복사해 고쳤다. `nb/sfxkit.finish()`에 라우드니스 목표용 리미터(최대 4 dB, 이번엔 0 dB 사용)와 앞 무음 트림 기록 추가. 새 모듈: `nb/orch.py`(활 현악·합창 포먼트·교회 종·하프·팀파니), `nb/epic.py`(스피카토/마르카토 앙상블·금관 섹션·심벌 등), `nb/orch.py`에 파이프 오르간·그란 카사·탐탐 추가. 철 충돌 모달 합성 `iron()`은 `make_sfx.py`.
