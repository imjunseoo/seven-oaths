## FX 메모 (전부 배경 투명, 조명 무시용)
- `fx_slash_*`: 주인공과 같은 캔버스·피벗 → 타격 프레임에 그대로 겹치면 칼 궤적과 맞음(확인: `ArtSource/previews/fx/overlay_check.png`). 흰 심 → 얼음 파랑 가장자리, 프레임마다 꼬리부터 사라지고 얇아짐, 끝에 반짝이.
  - `fx_slash_1`/`fx_slash_air`: 수평 타원(가로 베기). `fx_slash_2`: 사선 원호. `fx_slash_3`(낙하 마무리, **160×80 · 9×45ms**, 주인공 캔버스 기준 (+32,+16), 착지점 = (92,79)): 굵은 빛기둥 + 바닥 흰 돔 섬광 → 바닥을 따라 퍼지는 납작한 충격 링 + 수정 가시 7개 솟음 → 금 가고 부서짐 + 돌 파편이 포물선으로 튀고 떨어짐 + 먼지 → 떠오르는 빛 알갱이. (이전 설명: x=60에 위에서 내리꽂는 빛기둥(0: 굵게 → 점점 가늘게 위로 사라짐) + 바닥 흰 섬광 → 바닥을 따라 양옆으로 퍼지는 충격파·수정 가시·파편·금. `fx_slash_heavy`: 가장 두꺼운 원호.
  - `fx_slash_charge`(128×64): 주인공 캔버스를 가운데에 둔 기준(주인공 x + 16). 올려 베기 원호 + 앞쪽 바닥에서 수정 가시 5개가 차례로 솟고 마지막 프레임에 부서짐.
- `fx_dash`(96×32, v0.3): 피벗 왼쪽 가운데(y 15~16) = 대쉬 시작점. 오른쪽으로 긴 흰→얼음 파랑 줄(오른쪽 끝 뾰족, 왼쪽 꼬리 디더), 프레임마다 꼬리가 앞으로 먹혀 들어가며 얇아짐 + 위아래 속도선·반짝이. 미리보기 `ArtSource/previews/review/dash_attack_x3.gif`.
- `fx_light_sword`(60×15, 1프레임, v1.1): 대쉬 판정 중 주인공 대신 날아가는 빛의 검. 폼멜(마름모) → 손잡이(감은 띠) → 수정 십자 가드(x 15~17) → 날(x 18~59, 끝 뾰족). 가운데 흰색 → G/F → 바깥 1px 테두리 `#1d5ba8`(가산 혼합 시 희미한 빛 테두리). 피벗 가운데.
- `fx_rubble`(8×8, 태그 a~d, 각 1프레임, 새로 추가): 코드 파티클용 돌 파편(석재 4단계). 마무리 착지 때 12~16개를 중력·튕김으로.
- `fx_light_orb`(24×24, `loop` 4×60, 새로 추가·선택): 마무리 중 빛의 구 가산 혼합용(주인공 3~6프레임에 구가 이미 그려져 있음).
- `fx_hit_spark`(약) / `fx_hit_heavy`(강) / `fx_hit_ring`(충격 링, 5단계로 퍼짐): 중앙 피벗.
- `fx_crystal_shard` a/b/c: 8×8 파편.
- `fx_corrupt_burst`: 진홍 섬광 → 검붉은 연기가 끓어오름(보라 테두리) → 위로 흩어지는 잔불.

## 적 애니메이션 '끓음' 수정 (사용자 피드백, 2026-11-18)
- 원인: 리그가 프레임마다 몸을 다시 래스터해서(숨쉬기로 목·어깨 좌표가 소수점만큼 바뀜) 후드·투구·외곽선이 1px씩 들쭉날쭉, 석궁은 매 프레임 가는 선으로 다시 그려져 노이즈처럼 깜빡임.
- 원칙(`infantry.py` `layers/breathing/walking`): **자세 하나당 몸을 한 번만 그리고 정수 픽셀로만 옮김**. idle·aim = 상체(몸통+머리+무기)만 1px 내려감(0,0,1,1). walk = 상체 고정(두 발이 땅에 닿을 때 1px 내려감) + 다리만 새로. 프레임 차이는 의도한 색 변화(눈빛·균열 맥동)만 남음.
- 석궁은 손으로 찍은 고정 그림(`xbow_sprites.py`: aim·fired·low·recoil·down, 2px 나무 몸통 + 강철 활 + 볼트)을 손에 붙임. shoot = 같은 조준 자세에서 그림만 fired로 바꾸고 섬광. broken = 무릎 꿇은 한 장을 1px씩 흔듦.
- 같은 문제가 있던 방패병·검병 idle/walk에도 적용. 대기·걷기 프레임 간 차이: 최대 174px → 25px 이하(남은 건 눈·균열 색).
- 미리보기: `ArtSource/previews/review/enemies_stable_idle_walk.png`, `crossbow_idle_x4.gif`, `crossbow_walk_x4.gif`.

## 주의: Unity 2d.aseprite 3.0.1 임포터 버그 (메인 세션 확인, 2026-11-18)
