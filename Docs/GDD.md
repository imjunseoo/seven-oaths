# 일곱 서약 (Seven Oaths) — GDD v0.3

2D 도트 · 다크 판타지 · 횡스크롤 액션 어드벤처. Unity 6000.3.5f2 (2D URP). 타겟: Windows / Steam, 키보드 + 게임패드.
품질 기준선: 1HP Studio의 *INARI* 트레일러(이펙트·타격감·조명). 캐릭터·색·연출 언어는 우리 것으로 만든다.

## 한 줄 컨셉
마교에 침식된 성국에서, 수정검을 든 은발의 기사가 타락한 전설의 7기사를 차례로 쓰러뜨린다.
**무겁게 때리고, 회피로 끊고, 다시 때린다.**

## 코어 루프
```
지역 진입 → 전투(무거운 공격 ↔ 회피 캔슬) → 기사 보스 → 서약 계승(새 기술) + 침식 흡수 → 다음 지역
```

## 전투 원칙
- 공격은 정직하고 무겁다: 선딜이 분명하고, 맞으면 히트스톱·흔들림·넉백이 강하다.
- 날렵함은 회피에서: 공격 후딜을 회피로 끊는다. 회피 직후 공격 = 전용 **회피 베기**.
- 박자로 싸운다: 한 방 → 회피로 끊기 → 한 방. 연타 게임이 아니다.
- 적은 **자세 게이지**: 무거운 타격으로 무너뜨림 → **처형**(가장 큰 타격감).

### 대쉬 공격
- 조준 방향(360°)으로 8px/f × 9f ≈ 72px 돌진, 지나가는 적을 전부 벤다(적 관통). 판정 중 무적.
- 땅에서는 아래로 조준해도 수평. 쿨다운 40f. 공중 1회, **적을 맞히면 공중 대쉬·공중 베기 회복**(공중 연계).
- 선딜 5f 동안 공중에서 잠깐 멈춤(예비 동작). 끝나면 2px/f로 미끄러지며 후딜.
- **연출(사용자 아이디어)**: 판정 9f 동안 몸이 완전히 사라지고 **조준 방향을 가리키는 '빛의 검'**이 되어 날아간다(빛의 검 잔상 + 빛 입자). 끝나면 고리 섬광·파편과 함께 몸이 다시 맺힌다(적을 맞혔으면 더 크게).

- 공격 중 전진: 선딜 마지막 3f + 판정 동안 1.2px/f (베기 3·강공 2.0px/f).
- 차지 홀드 중 슈퍼아머(피해는 받지만 경직 없음).
- 공중 베기 중 중력 ×0.4.

### 베기 3 — 빛의 구 낙하 마무리 (v0.4, 사용자 요청)
- 모으기 20f → 빛으로 녹음 6f → **구가 되어 앞위로 비행 12f(최대 +44, +64, 감속)** → 정지 14f(맥동) → **수직 낙하 5f** → 착지 = 타격.
- **구 상태(비행·정지 26~51f)에서 A/D로 좌우 조작**(1.8px/f, 최대 ±48px), 내리꽂을 방향도 바뀜(사용자 요청).
- 사라진 동안(20~56f) 무적. 앞쪽 90px 안에 적이 있으면 칼끝(+12)이 그 적에 오도록 전진 거리를 줄인다(적 위에서 내리꽂기).
- 착지: 판정은 바닥을 따라 앞 −16~40, 높이 0~24. 맞든 안 맞든 4px·14f 흔들림 + 아래로 반동 + 진동 + 돌 파편 14개 + 먼지.
- 높은 데서 떨어지면 땅에 닿을 때까지 타격 프레임을 미룬다(최대 40f).

### 회피
- 총 22f, 거리 약 56px. 무적 1~10f. 11f부터 공격으로 캔슬(→ 회피 베기), 16f부터 다시 회피 가능.
- **퍼펙트 회피**: 적 판정이 무적 1~6f 안에 겹치면 → 0.35배속 0.4초 + 잔상, 다음 공격 1회 피해·자세 피해 ×1.5.

### 이동
**걷지 않고 낮게 숙여 미끄러지는 질주** 3.0px/f(가속·감속 0.6, 뒤에 검은 잔상 — 사용자 요청 v0.5) · 점프 초속 6.2px/f · 중력 0.38px/f² · 최대 낙하 7px/f · 점프 키를 떼면 상승 속도 ×0.5(낮은 점프). 최고 높이 약 50px.

## 적 (단계 1)
### 침식된 성국 병사 `soldier`
- HP 60 · 자세 45 · 걷기 1.0px/f · 인식 220px · 공격 거리 44px.
- 내려베기: 준비 28f(10f째 붉은 번뜩임 = 예고) → 판정 4f → 후딜 32f. 피해 15. 쿨다운 40~80f.
- 경직: 약 14f · 강 22f · 마무리 30f(띄움). 준비 중에 맞으면 끊긴다(판정 중엔 안 끊김).
- 넉백(px/f): 약 1.5 · 강 3.0 · 마무리 5.0 + 위로 2.5.

### 수련용 허수아비 `dummy`
- HP 무한 · 자세 60 · 무너짐 150f. 처형하면 쓰러졌다가 다시 선다.

### 자세 공식
- 맞을 때 `자세 -= 자세피해 × (퍼펙트 반격 ? 1.5 : 1)`. 0 이하 → **무너짐** 120f(처형 가능), 끝나면 자세 가득.
- 60f 동안 안 맞으면 초당 최대치의 20% 회복.

### 주인공
- HP 100. 맞으면 무적 45f. 처형 시 HP +10.

## 시점·아트
- 이동은 2D, 스프라이트는 **3/4 사선뷰**(몸통이 카메라 쪽으로 30~45° 틀어짐). **오른쪽을 보는 기준**으로 그리고 코드가 좌우 반전.
- 내부 해상도 480×270, 정수 배율 업스케일. 월드는 저해상도 RT에 그리고, 블룸·플래시는 화면 해상도에서 → 도트는 또렷하게, 빛은 부드럽게.
- URP 2D 라이트: 어두운 전역광 + 횃불·달빛·수정검 포인트 라이트. 타격 순간 라이트 점멸.
- 크기: 주인공 키 ~44px · 일반 적 40~56px · 기사 보스 64~96px.
- 색 언어: 주인공·성국 = 은백·검정·얼음 파랑(수정) / 침식 = 검정·진홍·탁한 보라 / 세계 = 차가운 석재 + 따뜻한 횃불.
- 주인공(키 일러스트 `Docs/ref/heroine_key_art.png`):
  - 살릴 것: 긴 은발 실루엣(동작마다 흩날림), 머리의 파란 수정 장식 2개, 빛나는 수정 장검(십자 가드), 흰 숄더 케이프, 검은 몸통·소매·장갑, 파란 띠
  - 생략: 장갑 손가락, 버클, 어깨 노출 디테일
- 수정검 이펙트 테마: 베기 궤적 흰색→얼음 파랑, 타격 시 수정 파편, 차지 공격 시 수정 가시.

## 세계관 (진행과 연결)
- 7기사는 각자 하나의 서약(미덕)을 맹세한 성국의 수호자. 마교의 **침식**이 서약을 뒤틀어 괴물로 만들었다.
- 기사를 쓰러뜨리면 서약을 계승(새 기술). 동시에 수정검이 침식을 빨아들여 **검과 머리 장식에 검붉은 금이 늘어난다** → 진행이 눈에 보이고, 결말의 질문은 "그 침식은 어디로 갔나".

| # | 기사 | 서약 → 침식 | 싸움 방식 | 계승 기술 |
|---|---|---|---|---|
| 1 | 철벽 | 인내 → 고립 | 대방패, 느리고 묵직, 자세 붕괴를 가르침 | 패리 |
| 2 | 맹렬 | 용맹 → 광기 | 쌍도끼 연타·돌진 | 돌진 베기 |
| 3 | 자비 | 자비 → 집착 | 망자 소환, 성가 장판 | 처형 회복 강화 |
| 4 | 심판 | 정의 → 무차별 처단 | 처형인 대검, 광역 | 차지 단계 +1 |
| 5 | 창공 | 충의 → 맹종 | 창, 공중전 | 2단 점프 / 공중 찌르기 |
| 6 | 거울 | 명예 → 허영 | 결투, 환영 분신 | 퍼펙트 회피 잔상 반격 |
| 7 | 기사단장 | 신앙 → 광신 | 모든 기술 | 결말 |

- **투명벽 금지 규칙**: 벽 판정에는 반드시 그림이 있어야 한다. 입구 창살 판정은 하늘 끝까지 이어지며, 창살 그림(96px) 위로는 붉은 봉인 장벽을 그린다(전투방 창살도 같음). 몸 밀어내기는 벽에서 멈추고, 모자란 만큼 적을 민다(벽을 뚫거나 벽 위로 튕기지 않음).
- 처형: 1페이즈 무너짐 처형 = 피해 90 + 방패에 금. 마지막 처형 = 갑옷이 벗겨지며 침식이 흩어지고 수정검이 침식을 빨아들임(검에 첫 검붉은 금) → **서약 유물 획득**.

## 서약 유물 (장비) v0.1 (2-3 구현됨)
- 쓰러뜨린 기사가 남긴 **서약의 문장(유물)**. 장착하면 그 기사의 서약(기술)을 쓸 수 있다. 장착 칸 3개 → 7개 중 무엇을 낄지가 빌드 선택.
- **장착 UI**(Tab): 게임이 멈추고 장착 칸 3 + 보유 유물 목록 + 설명(이름·서약·효과·짧은 이야기). 클릭으로 장착/해제. 유물을 얻으면 이 창이 자동으로 열리며 새 유물이 반짝인다.
- 유물 ①「철벽의 문장 — 인내」: **패리**. 방향키 없이 Shift를 누르면 그 자리에서 검을 세워 받아냄(받기 창 8f, 실패 시 후딜 14f). 성공하면 피해 0, 적 자세 큰 피해(일반 적은 30f 휘청, 보스는 자세 25%), 히트스톱 10f + 흰 섬광, 다음 공격 반격 판정. 석궁 화살은 되받아침. 방향키를 누른 채 Shift는 평소처럼 회피.
  - 구현 세부: 앞(조준 쪽)에서 온 공격만. 땅 충격파도 받을 수 있음. 보스 돌진도 받아낼 수 있지만 보스는 그대로 지나감(자세만 깎임). 성공 직후 14f 무적, 반격 자세 18f(언제든 베기·대쉬·회피·패리로 이어짐, 히트스톱 중 누른 것도 버퍼로 나감). 되받아친 화살 = 피해 20·자세 20, 속도 ×1.4.
  - **반격 오의(사용자 요청 v2)**: 근접 패리에 성공하면 **시간 정지(크로노스피어)** — 받아낸 곳에 푸른 구체(반경 72)가 펼쳐지고 모두 멈춤(54틱 ≈ 0.9초, 화면 "좌클릭 — 반격" + 줄어드는 막대). 시간이 멈춘 동안 주인공만 **뒤로 크게 미끄러지며(약 35px, 14틱) 칼을 바닥에 짚고 버팀**(칼끝 불꽃, `parry_slide`). 그 안에 좌클릭 → 칼을 뽑아 **앞으로 빛 대쉬(6틱 × 10px)** → 빛과 함께 사라짐 → 구체 안의 적에게 직선 참격 9줄 난사(5틱 간격 — 느리고 무겁게, 각 7·자세 5, fx_riposte_barrage) → 약 0.37초 정적(폭발 그림이 빨아들임) → '쾅'(30·자세 30, 마무리 등급) → 30틱 가라앉음 → 사라진 자리에 **칼을 짚고 무릎 꿇은 채** 나타남(28틱, `parry_slide` 2~3) → 칼을 뽑으며 일어섬(17틱, `parry_rise`, 베기·대쉬·회피·점프로 끊기 가능). 일어설 때까지 무적(45틱). 방패 무시. 오의 동안 적은 계속 멈춰 있다. 좌클릭하지 않으면 시간이 다시 흐르고 기존 반격 자세(다음 공격 반격 판정). 화살 되받아치기는 시간 정지 없음.
  - 얻는 법: 「철벽」이 쓰러지고 100f 뒤 그 자리에 문장이 떠오름 → 닿으면 획득 + 빈 칸이면 자동 장착 → 0.8초 뒤 장착 창이 열리며 새 유물이 반짝임. 이미 가졌으면 다시 안 떨어짐.
  - 시험용: F1 패널 "패리 유물 받기", 자동 검증 `-soRelic`.
- 나머지 6개는 7기사 표의 "계승 기술"(돌진 베기, 처형 회복 강화, 차지 단계 +1, 2단 점프, 잔상 반격 …). 장착 창에는 "?"로 자리만 보인다.

## 저장
- `save.json`(persistentDataPath): 레벨·마지막 성수 제단·유물·설정(볼륨·전체 화면·패드 진동). 제단을 밝힐 때, 레벨을 옮길 때, 저장 후 종료·창 닫을 때 저장. 다음 실행은 그 제단에서 시작.

## 기술 규칙
- 입력: Input System + `InputSystemUIInputModule`(구식 StandaloneInputModule 금지). 액션은 코드로 생성.
- 전투 규칙은 **순수 C#**(`SevenOaths.Model`, 엔진 참조 없음) · 고정 60Hz `Step()` · 히트스톱·슬로도 모델이 관리 → EditMode 테스트로 검증.
- 충돌은 직접 만든 AABB(물리엔진 X). 좌표 단위 = 픽셀, 뷰는 PPU 32로 변환.
- 판정 상자는 지금은 `Moves.cs`에 코드로 정의. 아트의 "타격 프레임"이 판정 시작에 맞도록 뷰가 단계별로 시간을 맞춘다(ASSET_SPEC 5절).
- UI: uGUI + TextMeshPro(Galmuri), 코드로 생성. OnGUI 금지.
- 스프라이트: PPU 32, Point, 무압축. `.aseprite` → `com.unity.2d.aseprite`, **태그명 = 애니메이션 상태명**.
- 검증: `-so*` 명령줄 옵션(DebugAutomation)으로 빌드를 자동 조작·캡처.
