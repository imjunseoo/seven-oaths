# PixelLab 동작 시험: A안 원본 → idle·run (2026-11-20, 캐릭터·NPC 세션)

원본을 그대로 실었다. 손보정은 하지 않았다. 게임 파일(`Assets/`)은 건드리지 않았고, 리그 HD 작업은 멈춘 채 그대로 뒀다.

## 크레딧
- 시작: 유료 $0, 플랜 생성 0, **오늘 보너스 5회**.
- 사용: `animate_image` 2번 × 2회 = **4회**(idle 2, run 2). 생성 결과의 cost 줄이 각 2회였다. 남은 보너스는 1회이고 결제는 없다.

## 설정
- 입력은 `characters_v2/raw/pixellab_heroineA_72x76.png`(A안 PixelLab 원본, 손보정본 아님)이다. 144×96 캔버스에 발 95행, 목(원본 50열)을 가로 72에 맞춰 놓았다 → `input_A_raw_144x96.png`
- idle: frame_count 6(옛 idle 6프레임), seed 7. 동작 설명은 "제자리 숨쉬기, 머리카락·케이프 살짝 흔들림, 발 고정, 검 고정".
- run: frame_count 8(옛 run 8프레임), seed 7. 동작 설명은 "오른쪽으로 달리기, 보폭, 팔 흔들기, 머리카락·케이프 뒤로 날림, 몸 앞으로 기울임, 검은 낮게".
- 결과는 프레임 수 + 1장이다(0 = 입력 그대로). 검과 머리카락은 잘리지 않았다. 모든 프레임이 캔버스 안에 있고 발은 95행이다.

## 파일
- `raw/idle_0..6.png`, `raw/run_0..8.png`: PixelLab 원본(0 = 입력).
- `idle_strip_x3.png`, `run_strip_x3.png`: 프레임 줄(×3).
- `idle_x3.gif`(생성 1~6, 120ms), `run_x3.gif`(생성 1~8, 60ms): 옛 idle·run과 같은 프레임 수·ms.
- `compare_sheet.png`: PixelLab idle·run | 리그 HD idle·run(승인 시트와 같은 프레임). ×4, 24px 칸, 판정 21×60.
- 다시 만들기: `python ArtSource/src/characters_hd/pixellab_test.py`

## 프레임마다 흔들림 (얼굴 % = 입력과 비교해 얼굴 상자 픽셀이 바뀐 비율, 새 색 = 입력 25색에 없던 색 수)
### idle
- 0: 입력 원본.
- 1: 얼굴 74%(눈이 커지고 둥글어짐, 볼에 주황 그늘) · 새 색 26 · 검은 거의 제자리(검 영역 41%).
- 2: 얼굴 84%(고개가 조금 정면으로 돌고 얼굴이 1~2px 왼쪽으로, 입이 거의 안 보임) · 새 색 21 · 검 92%(칼끝·각도가 몇 px 움직이고, 손에 쥔 갈색 칼자루가 사라짐).
- 3: 얼굴 84%(2와 비슷, 머리끝 모양 바뀜) · 새 색 22 · 검 94%(손 위치 바뀜).
- 4: 얼굴 78%(앞머리 결 바뀜) · 새 색 22 · 검 95%.
- 5: 얼굴 66%(눈이 다시 가늘어지고 앞머리가 원본 쪽으로) · 새 색 24 · 검 93%.
- 6: 얼굴 57%(원본에 가장 가까움, 입이 돌아옴) · 새 색 22 · 검 92%.
- 앞 프레임과 비교하면 22~61%가 바뀐다. 숨쉬기 동작보다 그림 전체가 부글거리는 게 더 눈에 띈다.

### run
- 1: 얼굴 78%(눈 커짐, 입 작아짐) · 새 색 27 · 검 96%(칼날이 길어지고 칼끝이 왼쪽 아래로). 한 발 앞으로.
- 2: 얼굴 84%(눈 더 커지고 입 위치 바뀜) · 새 색 26 · 검 99%. 다리를 벌림.
- 3: 얼굴 79% · 새 색 29 · 검 88%. 다리 교차.
- 4: 얼굴 80%(얼굴 윤곽이 흐려짐) · 새 색 29 · 검 82%(갈색 칼자루 사라짐).
- 5: 얼굴 79%(눈 모양 바뀜, 얼굴 디테일 줄어듦) · 새 색 26 · 검 97%(칼이 더 수평으로 들림). 오른팔 앞으로.
- 6: 얼굴 81%(가장 뭉개짐) · 새 색 22 · 검 99%. 머리카락이 뒤로 날리기 시작.
- 7: 얼굴 80% · 새 색 25 · 검 99%. 뒷다리 차올림.
- 8: 얼굴 79% · 새 색 23 · 검 97%.
- 앞 프레임과 비교하면 66~83%가 바뀐다. **달리기보다는 제자리 걷기에 가깝다.** 몸을 앞으로 기울이지 않고, 두 발이 다 뜨는 순간이 없으며, 팔도 거의 흔들지 않는다. 머리카락은 5~8에서만 조금 날린다.

## 정리
- 장점: 한 장 한 장은 A안 원본처럼 디테일이 많다(갑옷 팔, 케이프 음영, 은발 결).
- 단점:
  - 프레임마다 얼굴이 다시 그려진다(입력 대비 57~84%). 눈 크기, 고개 방향, 입이 계속 바뀐다.
  - 색이 프레임마다 21~29개씩 새로 생긴다. 팔레트가 지켜지지 않는다.
  - 검의 각도·길이·칼자루가 계속 바뀐다.
  - run은 걷기 수준이다.
- 게임에 쓰려면 프레임마다 손을 많이 대야 한다. 팔레트 다시 맞추기, 고정된 A 얼굴 붙이기, 검 고정이 필요하고, run은 사실상 다시 그려야 한다. 동작 29개 × 하루 5회 한도도 걸린다(144×96 한 동작에 2회).
